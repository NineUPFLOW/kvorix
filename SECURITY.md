# Безопасность

## После установки

1. **Смените пароль** пользователя `agent` (в образе, собранном `kvorix-build-image`, — `kvorix`): Настройки → Учётные записи или `passwd`.
   При первом входе по SSH/в консоли система сама попросит его сменить.
2. `root` заблокирован; администрирование — через `sudo`.
3. `agent` выполняет `sudo` **без пароля** — так работают Настройки (установка программ, сеть, службы).
   Если мини-ПК пользуются чужие люди, уберите это правило: `sudo rm /etc/sudoers.d/agent`
   (часть кнопок в Настройках начнёт спрашивать пароль или перестанет работать).
4. SSH открыт в домашней сети. Если не нужен: Настройки → Безопасность или `sudo systemctl disable --now ssh`.

## Что у каждого мини-ПК своё

Создаётся при установке (`kvorix-firstboot`), в репозитории и в собранных образах отсутствует:

- ключи SSH (`/etc/ssh/ssh_host_*`);
- пароль показа экрана (`/etc/kvorix/vnc.pass*`) и секретный адрес noVNC (`/etc/kvorix/novnc.token`);
- темы ntfy и токен «Доступа ИИ» (`/etc/kvorix/ai.conf`, только root).

Не публикуйте эти файлы, ключи из `~/.ssh`, данные Tailscale (`/var/lib/tailscale`) и пароли Wi-Fi
(`/etc/NetworkManager/system-connections`).

## Сетевые службы

| Служба | Слушает | Доступ |
|---|---|---|
| SSH | 22 | пароль/ключ |
| x11vnc | 127.0.0.1:5900 | только локально |
| noVNC (nginx) | 6080 | только по секретному пути, иначе 404; не открывайте порт в интернет |
| Samba / DLNA / AirPlay | локальная сеть | выключены по умолчанию |
| Tailscale | — | только ваша сеть Tailscale; Funnel выключен |

## Доступ ИИ

Выключен по умолчанию. Когда включён, на мини-ПК работает обратный SSH (upterm); коды сессий публикуются в
теме ntfy мини-ПК, войти можно только ключом из `/etc/agent-access/guests_authorized_keys`. Выключайте, когда не нужен.
