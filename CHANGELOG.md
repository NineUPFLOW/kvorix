# История версий

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-03

Первый публичный выпуск.

### Добавлено
- Kvorix для Tanix TX3 (S905X3) на Armbian ophub 26.11 / Debian 13 / ядро 6.12.112-ophub, установка `install.sh`.
- Оболочка в стиле Windows 11: панель задач, «Пуск» с поиском, горячие клавиши Win.
- Приложение «Настройки» с поиском, порядок разделов как в Windows 11.
- Тема значков Kvorix для всей системы и автоматические значки для новых программ (`kvorix-icons.path`).
- Определение монитора по EDID через DDC (`hdmi-autodetect`), режим подгонки краёв для ТВ.
- Передняя панель 88:88 (FD6551) с настройками.
- Показ экрана на телефон по QR (noVNC), обход блокировок (zapret), Tailscale.
- Первый запуск: свои ключи SSH, пароль VNC, токен noVNC и темы «Доступа ИИ» у каждой приставки (`kvorix-firstboot`).
- Сборка своего образа без личных данных (`kvorix-build-image`) — для своих приставок.
- Автотест (`test-all.sh`, 127 проверок) и проверка здоровья (`kvorix-health-check`).

### Исправлено
- Панель задач, меню и запущенные из них программы получали приоритет `nice 10` от службы экрана — тормоза.
- Tailscale после перезагрузки мог остаться «офлайн» — сторож восстанавливает связь.
- Ложная ошибка автотеста поиска в «Пуске».

### Удалено
- Дубли программ (второй калькулятор, системный монитор, терминалы, видеоплееры, просмотрщик).
- Остатки кластера, отключённые старые службы, дубли скриптов доступа.
- Лишняя фоновая нагрузка: ежедневная перестройка man, CUPS запускается только при печати.
