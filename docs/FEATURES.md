# Возможности Kvorix

## Рабочий стол и оболочка

| Что | Как пользоваться |
|---|---|
| Панель задач по центру (свой `rsaarm-taskbar`) | закреплённые программы, открытые окна, сеть, звук, часы, выключение |
| Меню «Пуск» (`rsaarm-menu`) | клавиша Win; поиск программ, файлов и параметров; «Все приложения»; рекомендуемые |
| Горячие клавиши | Win+E — Проводник, Win+I — Настройки, Win+R — Выполнить, Win+P — разрешение экрана, Win+V — буфер обмена, Win+S — поиск, Ctrl+Shift+Esc / Win+X — диспетчер задач, Win+←/→ — окно к краю |
| Значки Kvorix | одна тема для всей системы; новые программы получают значок сами (`kvorix-icons.path`) |
| Темы светлая/тёмная | Настройки → Оформление (цвет акцента, прозрачность, анимации, обводка окон) |
| Ножницы | «Снимок экрана (Ножницы)» в «Пуске» — в буфер и PNG |
| Диспетчер задач | свой `kvorix-taskmanager`: процессы, нагрузка, завершение |

## Настройки (`armbian-center`)

Главная (плитки и состояние: процессор, память, температура), **Система** — экран, звук, питание, хранилище,
быстродействие; **Устройства и сеть** — сеть и интернет, Bluetooth, устройства (флешки, принтеры, сканеры, камеры,
телефоны, геймпады, передняя панель, показ экрана на телефон); **Персонализация** — оформление, обои, время и язык;
**Приложения** — установка/удаление (магазин на apt), автозагрузка, фоновые службы; **Учётные записи и защита** —
пользователи, безопасность (SSH, брандмауэр), обновления, доступ ИИ, о системе. Поиск сверху находит любой параметр.

## Экран и звук

- **Автоподстройка под монитор** (`hdmi-autodetect`): TX3 не видит подключение HDMI, поэтому служба раз в 3 с
  читает EDID по линии DDC, при смене монитора отдаёт EDID ядру и ставит его режим, перестраивая панель и меню.
- **Режим для ТВ «подгонка краёв»** (`armbian-screen-fit`): свой режим со сдвигом, если ТВ обрезает края.
- Свой режим для каждого монитора: Win+P → «Разрешение экрана».
- Звук по HDMI (PipeWire), громкость с клавиатуры и медиаклавиши (`kvorix-mediakeys`).
- Заставка загрузки Plymouth `kvorix`, один видеорежим от включения до рабочего стола.

## Устройства

- Флешки и диски монтируются сами (udiskie), окно «Хранилище и диски» (`kvorix-disks`).
- Принтеры и сканеры (CUPS, HPLIP, Gutenprint, ESC/P-R, sane-airscan).
- Телефоны (MTP, iPhone через usbmuxd), Bluetooth-наушники/колонки/мыши (blueman, bluez).
- ИК-пульт NEC (`/etc/rc_keymaps/kvorix-tx3.toml`), USB-пульты и «аэромыши».
- **Передняя панель 88:88** (FD6551, служба `front-panel`): часы, дата, температура, загрузка CPU, память, диск,
  сигнал Wi-Fi, время работы; яркость, ночной режим — Настройки → Устройства → «Индикатор на корпусе».

## Сеть

- **Показ экрана на телефон** (Настройки → Устройства → «Экран на телефоне»): QR-код открывает рабочий стол
  в браузере телефона. x11vnc (только 127.0.0.1) → websockify → nginx с секретным путём (`kvorix-novnc-token`).
  Работает только в домашней сети.
- **Обход блокировок zapret** (`kvorix-zapret`, nfqws + nftables): списки сайтов в `/etc/kvorix/zapret-hosts.txt`.
- **Tailscale** — доступ к приставке из своей сети Tailscale; сторож перезапускает его, если связь «замёрзла».
- Установлены, но выключены (включаются вручную `sudo systemctl enable --now …`): общая папка Samba (`smbd`, `/srv/share`), DLNA (`minidlna`), AirPlay-звук (`shairport-sync`).

## Быстродействие

- CPU до 2,1 ГГц, governor `ondemand`; zram-подкачка.
- GPU Panfrost: X11 `glamor`, Chromium с аппаратной отрисовкой.
- Панель, меню и Настройки предзапускаются; приоритет обычный (служба экрана со `Nice=10` сбрасывает его для оболочки).
- Аппаратное декодирование видео (meson-vdec) **выключено** — нестабильно на этом ядре.

## Обслуживание

| Служба / команда | Что делает |
|---|---|
| `box-watchdog.timer` | каждую минуту: связь с роутером, SSH, восстановление Tailscale, температура (радио не трогает) |
| `kvorix-health-check` | проверка здоровья системы (`--json` для программ) |
| `kvorix-config-snapshot.timer` | снимки настроек в `/var/backups/kvorix-config-private` |
| `kvorix-mode-heal.timer` | возвращает видеорежим, если он сбился |
| `kvorix-make-icons` | значки для всех программ (запускается сам при установке программ) |
| `kvorix-build-image` | собрать свой образ прошивки без личных данных |
| `armbian-install` | перенести систему с карты на eMMC |

## Доступ ИИ (выключен по умолчанию)

Настройки → Доступ ИИ позволяет на время пустить ИИ-агента (например, Claude Code) на приставку для обслуживания:
обратный SSH через upterm, коды сессий публикуются в **своей** теме ntfy этой приставки (создаётся при первом запуске,
`/etc/kvorix/ai.conf`, доступ только root). Войти можно только ключом, который вы сами добавите. Пока выключено — не
работает ничего из этого.

Для Доступа ИИ нужен [upterm](https://github.com/owenthereal/upterm/releases) в `/usr/local/bin/upterm`
(в образе уже есть; при установке через `install.sh` поставьте вручную).
