# Установка Kvorix

## Что нужно

- Tanix TX3 (S905X3) — проверено на ревизии **TX3 (BZ)**, 2 ГБ ОЗУ / 16 ГБ eMMC.
- microSD или USB-флешка **от 8 ГБ** (лучше A1/A2 или USB 3.0 — от скорости носителя зависит скорость системы).
- Монитор или ТВ по HDMI, USB-клавиатура и мышь (или беспроводной USB-пульт/«аэромышь»).
- Компьютер для записи образа.

## 1. Записать образ

1. Скачайте `kvorix-<версия>-tx3.img.xz` из [Releases](https://github.com/NineUPFLOW/kvorix/releases)
   и, по желанию, проверьте сумму: `sha256sum -c kvorix-<версия>-tx3.img.xz.sha256`.
2. Запишите образ на носитель:
   - **Windows / macOS / Linux:** [balenaEtcher](https://etcher.balena.io/) → «Flash from file» → носитель → «Flash».
     Распаковывать `.xz` не нужно.
   - **Linux из терминала:** `xzcat kvorix-*.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync`
     (`/dev/sdX` — ваш носитель, **не** системный диск).

## 2. Загрузиться с карты

**Если на приставке Android (заводская прошивка):**

1. Выключите приставку из розетки, вставьте карту/флешку.
2. Зубочисткой зажмите кнопку **reset** в гнезде AV (сзади), не отпуская — включите питание.
3. Отпустите через 5–10 секунд, когда появится заставка. Дальше приставка будет загружаться с карты сама,
   пока она вставлена; без карты — снова Android.

**Если на приставке уже Armbian / Kvorix на eMMC:** Armbian ophub проверяет носители при загрузке —
вставьте карту и перезагрузитесь. Если грузится eMMC — загрузитесь способом с reset (выше).

## 3. Первый запуск

Первая загрузка идёт 2–4 минуты дольше обычной: служба `kvorix-firstboot`

- создаёт **свои** ключи SSH этой приставки;
- создаёт пароль показа экрана (VNC) и секретный адрес noVNC;
- создаёт свои темы и токен «Доступа ИИ» (сам доступ **выключен**);
- `armbian-resize-filesystem` растягивает раздел на весь носитель.

Затем откроется рабочий стол (вход автоматический).

**Пароль пользователя `agent` — `kvorix`.** Его спросят при первом входе по SSH или в консоли и попросят сменить.
Смените сразу: Настройки → Учётные записи, или в терминале `passwd`.

## 4. Подключить сеть

- Wi-Fi: значок сети на панели → выбрать сеть → пароль. Или Настройки → Сеть и интернет.
- Кабель: подключается сам.
- Часовой пояс и язык: Настройки → Время и язык.

## 5. Установить на встроенную память (eMMC) — по желанию

Система на eMMC работает быстрее карты. **Android будет стёрт.** Заводская прошивка — на вашей ответственности,
сделайте её копию заранее (например, Amlogic USB Burning Tool / образ с сайта производителя).

```bash
sudo armbian-install
```

Выберите модель **TX3** (S905X3), подтвердите. После «Done» выключите, выньте карту, включите.
